Connexion

Pas de mot de passe : vous recevez un e-mail de connexion à chaque fois. Le compte est créé automatiquement la première fois.

Deux façons de faire :
• Sans cliquer : dans l'e-mail, clic droit sur le bouton « Sign in » → « Copier l'adresse du lien », puis collez ici.
• Si vous avez déjà cliqué : une page « Ce site est inaccessible » (localhost) s'est ouverte. C'est normal. Cliquez dans la barre d'adresse de cette page, copiez toute l'adresse (Ctrl+A puis Ctrl+C), puis collez-la ici.

      Fiches d'information

      Le chat répond uniquement avec les fiches publiées. Une fiche passe par : brouillon → à valider → publiée. Rien n'est visible tant que ce n'est pas publié.

        Codes QR

        Chaque code ouvre votre page publique. Vous pouvez en créer plusieurs (accueil, salle d'attente, maternité…) et en désactiver un à tout moment.

        Suggestions des visiteurs

        Messages laissés par les visiteurs depuis la page publique. Ils sont visibles uniquement par le propriétaire et les membres ayant le rôle « Suggestions ». Le message du visiteur ne peut pas être modifié.
